Browse Programs by Category

SmartTV organizes programs by genre. To browse by category:

  1. Look at the category filters (All Genres, Comedy, Drama, Action, News, etc.)

  2. Select a category to view programs in that genre

  3. Browse the available programs

Search for Specific Programs

To search for a program by title:

  1. Select the Search box at the top of the screen

  2. Type the program name or keyword

  3. Results will appear as you type

  4. Select a program from the search results to view details

Program Information

When you select a program, you'll see:

  • Program title and thumbnail

  • Episode information (Season and episode number)

  • Description and genre

  • Air time and channel

  • Rating and reviews (if available)

Filter by Date

SmartTV lets you filter programs by date:

  1. Select a date (Today, Tomorrow, specific dates, etc.)

  2. View programs scheduled for that date

  3. Browse and select programs as needed

Next Steps
