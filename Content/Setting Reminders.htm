Setting Reminders for Programs

Set reminders so SmartTV notifies you before your favorite programs air.You can set reminders for individual programs or manage all your reminders in one place.

Access Your Reminders

  1. Open the SmartTV App.

  2. Select Reminders from the sidebar.

  3. You'll see your Reminders Dashboard.

View Your Reminders

The Reminders Dashboard displays:

  • All active reminders

  • Active reminders (currently set)

  • Completed reminders (aired or expired)

  • Upcoming reminders (scheduled to air soon)

Figure 6:Your Reminders Dashboard displaying active, upcoming, and

completed reminders with program details.

Set a New Reminder

Method 1: From Program Details

  1. Find a program using Browse or Search.

  2. Select the program.

  3. Select Set Reminder or Add Reminder.

  4. Choose your reminder preferences.

  5. Select Save Reminder.

Method 2: From Your Favorites

  1. Go to Favorites.

  2. Select Set Alert on a favorite program.

  3. Configure reminder settings.

  4. Select Save Reminder.

Add New Reminder Interface

When setting a reminder, you'll configure:

Program

- Search for and select the program you want a reminder for.

Date and Time

- Select the date the program airs.

- Set the time you want to be reminded.

Channel

- Select the channel where the program airs.

- Choose from available channels in a dropdown menu.

Notification Preference

- Enable or disable Push Notifications.

- Push Notifications alert you on connected devices.

Figure 7:The Add New Reminder interface showing program, date, time,

channel, and notification settings.

Reminder Status

Track your reminders by status:

Active Reminders

- Programs you've set reminders for that haven't aired yet.

- Status shows "ACTIVE" in green.

Upcoming Reminders

- Reminders scheduled to notify you soon.

- Status shows "UPCOMING" in yellow.

Completed Reminders

- Programs that have already aired.

- Status shows "COMPLETED" in gray.

Manage Reminders

View all your reminders in the Reminders Dashboard:

  1. Select a reminder to view details.

  2. See program information, air time, and channel.

  3. Edit or delete the reminder if needed.

Empty Reminders

If you haven't set any reminders yet:

  1. You'll see an empty state message.

  2. Select Add Reminder to create your first reminder.

  3. Or schedule programs and set alerts from the program details.

Figure 8:Empty Reminders screen when you haven't set any reminders yet.

 

Notification Settings

Customize how you receive reminders:

  1. Go to Settings.

  2. Select Notifications.

  3. Toggle Program Reminders on/off.

  4. Set Reminder Timing (minutes before program starts).

  5. Enable other notification preferences.

Limit on Reminders

SmartTV allows you to set multiple reminders. The number of active reminders may depend on your subscription plan.

Next Steps

After setting a reminder:

  • You'll receive notifications when the program is about to air

  • Check your Reminders Dashboard to view all active reminders

  • Manage notification preferences in Settings
