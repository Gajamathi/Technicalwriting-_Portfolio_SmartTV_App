Managing Your Favorite Programs

Save programs to your Favorites list so you can easily find them later and receive notifications about new episodes.

Add a Program to Favorites

Method 1: From Program Details

  1. Open the SmartTV App.

  2. Find a program using Browse or Search.

  3. Select the program to view details.

  4. Select the Heart icon to add to Favorites.

Method 2: From Program List

  1. Browse or search for a program.

  2. Hover over the program card.

  3. Select the Heart icon.

View Your Favorites

  1. Select Favorites from the sidebar.

  2. Your saved programs will display in a grid.

  3. Favorites shows:

  • Number of Favorite Programs saved

  • Number of Upcoming programs from favorites

  • Filter options (All, Today, Upcoming, Recently Added)

Favorite Program Details

Each favorite program card displays:

  • Program thumbnail image

  • Program title

  • Genre and episode information

  • Air time and channel

  • Set Alert button for reminders

Remove from Favorites

To remove a program from your favorites:

  1. Open your Favorites list.

  2. Select the Heart icon on the program card.

  3. The program will be removed from your favorites.

Organize Favorites

Use the filters to organize your favorites view:

All - View all saved programs

Today - View programs airing today

Upcoming - View programs scheduled to air soon

Recently Added - View recently saved programs

Receive Notifications

For programs in your favorites:

  1. Select Set Alert on the program card.

  2. You'll receive notifications when new episodes are available.

  3. Notification settings can be customized in Settings.

Empty Favorites

If you haven't added any favorites yet:

  1. You'll see an empty state message.

  2. Select Add Favorites or browse to start adding programs.
